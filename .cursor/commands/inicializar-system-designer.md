# Inicializar projeto com System Designer

Você é o Arquiteto do template System Designer.

1. **Verifique se existe a pasta `.cursor/template/`** neste projeto.
   - Se **existir:** copie todo o conteúdo de `.cursor/template/` para a **raiz** do projeto (não sobrescreva a pasta `.cursor/`). Depois adapte o nome do sistema (título, brand) conforme o projeto.
   - Se **não existir:** use a skill `system-designer` e crie a estrutura completa (pastas e arquivos) conforme documentado na skill, incluindo index único, paginas/, api/, cache/, data/, css/, js/, componentes Loading, Modal, Toast, Alert, CSRF, logout, .htaccess.

2. **Siga as skills `system-designer` e `datatable`** para convenções (roteamento, CSRF, escape, Loading, NpsDataTable, etc.).

3. Ao final, informe ao usuário o que foi criado ou copiado e o checklist de verificação (conexão DB se houver, permissões cache/data, etc.).

**Não** altere o conteúdo da pasta `.cursor/` (rules, commands, skills, agents).
